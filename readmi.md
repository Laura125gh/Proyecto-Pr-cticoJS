Proyecto Práctico JavaScript

1. ¿Qué hace mi proyecto?

Este proyecto es una página web realizada con HTML, CSS y JavaScript. Permite interactuar con diferentes funcionalidades del navegador y muestra información utilizando JavaScript.

2. ¿Qué funcionalidades implementé?

* Saludo personalizado utilizando el nombre ingresado por el usuario.
* Visualización del ancho y alto de la ventana.
* Detección del estado de conexión a Internet.
* Obtención de la ubicación del usuario.
* Botón para recargar la página.
* Modo oscuro.
* Mensajes dinámicos en la página.
* Al hacer clic en el título, cambia de color.
* Navegación por el historial de la página, permitiendo avanzar y retroceder.

3. ¿Qué conceptos de BOM utilicé?

Utilicé diferentes objetos y propiedades del BOM, entre ellos:

* window.innerWidth y window.innerHeight para obtener el tamaño de la ventana.
* window.addEventListener() para detectar cambios en el tamaño de la ventana.
* navigator.onLine para comprobar si el navegador está conectado a Internet.
* navigator.geolocation para obtener la ubicación del usuario.
* location.reload() para recargar la página.
* history para trabajar con el historial de navegación y poder avanzar o retroceder.

4. ¿Qué conceptos de DOM utilicé?

Utilicé el DOM para interactuar con los elementos HTML de la página.

Algunos conceptos utilizados fueron:

* document.getElementById()
* Modificación del contenido de elementos.
* Eventos mediante addEventListener().
* Uso de botones para ejecutar funciones.
* Modificación de elementos de la página mediante JavaScript.

5. ¿Qué funcionalidad extra agregué?

Como funcionalidad extra, agregué que al hacer clic en el título de la página, este cambia de color a azul. Como además el modo oscuro de la página.

6. ¿Qué fue lo que más me costó resolver?

Lo que más me costó fue resolver la funcionalidad para obtener la ubicación del usuario. Para poder hacerlo me fui ayudando con los videos de la clase y repasando los contenidos vistos. También me costó un poco volver a recordar cómo subir el proyecto y conectarlo con el repositorio local de GitHub, pero pude resolverlo siguiendo los pasos y practicando.
